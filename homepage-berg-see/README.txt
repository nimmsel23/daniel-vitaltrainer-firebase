Daniel Nimmrichter – Berg & See

START
ZIP vollständig entpacken und index.html im Browser öffnen.
Alle Bilder, Gestaltung und der Jahreszeitenwechsel sind enthalten.
Keine Installation und kein Build notwendig.

HOSTING
index.html und den Ordner assets gemeinsam in das Webverzeichnis hochladen.
Die Ordnerstruktur beibehalten. Das ZIP enthält keine Zugangsdaten.

BEARBEITEN
Texte, CSS und JavaScript stehen in index.html.
Bilder liegen in assets/.
Der Kontaktbutton öffnet das E-Mail-Programm. Profil-Links benötigen Internet.
